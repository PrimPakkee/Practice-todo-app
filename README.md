# Practice Todo App / TaskFlow AI Practice

这是一个用于练习 **Codex + React + Vite** 的个人效率管理项目。

项目从基础 Todo List 开始，逐步练习前端页面结构、状态管理、本地数据保存、视觉样式优化，以及后续前后端完整开发流程。

## 当前功能

- 添加任务
- 删除任务
- 标记任务完成 / 未完成
- 使用 localStorage 本地保存任务
- 深色科技感界面

## 技术栈

- React
- Vite
- JavaScript
- CSS
- localStorage

## 本地运行方式

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

启动后在浏览器中打开终端提示的本地地址，通常是：

```bash
http://127.0.0.1:5173/
```

## 项目规划

- Dashboard 布局
- Sidebar / Topbar
- 任务优先级
- 截止日期
- 搜索和筛选
- 后端 API
- SQLite 数据库
- 用户登录
- AI 任务助手

## 学习目标

- 熟悉 React 项目结构
- 熟悉 Codex 辅助编程流程
- 学会前端、后端、数据库、GitHub 的完整开发流程
