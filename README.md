# Practice Todo App / TaskFlow AI Practice

这是一个用于练习 **React + Vite + Codex** 的个人效率管理项目。

项目会从前端基础 Todo 开始，逐步演进为一个更完整的个人任务管理工具，用来练习页面结构、状态管理、本地存储、产品交互、后端 API、数据库和部署流程。

## 当前版本能力

- 多页面 Dashboard 布局
- Sidebar / Topbar 基础产品结构
- 完整 Tasks 页面
- 任务标题、状态、优先级、截止日期、标签、备注
- localStorage 本地保存
- Timeline 按任务状态分组
- Calendar 根据 dueDate 展示任务
- Analytics 基于真实任务数据统计
- 深色科技感界面、蓝紫渐变、毛玻璃卡片

## 技术栈

- React
- Vite
- JavaScript
- CSS
- localStorage

## 本地运行方式

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

启动后在浏览器中打开终端提示的本地地址，通常是：

```bash
http://127.0.0.1:5173/
```

## 版本规划

- `v0.1.x`：基础前端与核心 UI / 交互
- `v0.2.x`：完整前端产品化与高级前端功能
- `v0.3.x`：后端、API、数据库
- `v1.0.0`：可部署、可展示的正式版本

## 学习目标

- 熟悉 React 项目结构
- 熟悉 Codex 辅助编程流程
- 理解前端状态和 localStorage 本地存储
- 学会前端、后端、数据库、GitHub 的完整开发流程
